# مسار

تطبيق ويب شخصي (PWA) يعمل دون إنترنت: جدول اليوم والنسب، الدروس والتمارين، المشاريع والأهداف والمال، الخطة والاختبارات، الصحة والرياضة، وقسم لتتبّع العادات.

- كل البيانات على الجهاز ومشفّرة (AES-GCM) بمفتاح محمي بكلمة السر، مع رمز استرجاع.
- بلا مكتبات خارجية، ومزامنة مشفّرة اختيارية عبر Supabase (دوال masar_get و masar_put و masar_signup): `index.html`, `styles.css`, `data.js`, `app.js`, `sw.js`.
- التشغيل محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.
- النشر: GitHub Pages من الفرع الرئيسي، ثم من سفاري: مشاركة ← إضافة إلى الشاشة الرئيسية.
- عند أي تعديل: غيّر `CACHE` في `sw.js` ليصل التحديث للهاتف.
